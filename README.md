# 精细音量（Fine Volume）

一个 Android 应用，通过**分段映射**把物理音量键的步进精细化：把系统音量想象成「真实进度」，
App 在外面套一层「虚拟进度」，每段有自己的倍率，从而让某些区间走得慢、某些区间走得快。

## 工作原理

1. 系统音量被抽象成 `0..max` 个真实档位，App 再虚拟出 `virtualSteps`（默认 100）档。
2. 每次按音量键，虚拟档位 ±1，再按当前的分段倍率换算成真实系统音量 `index`。
3. 通过无障碍服务（AccessibilityService）消费掉音量键事件，阻止系统原生步进。

倍率 `c` 的含义：
- `c < 1`（如 0.6）：这一段「被压缩」，跨过它真实音量只走 60%，适合精细微调
- `c > 1`（如 2.0）：这一段「被拉伸」，跨过它真实音量走 200%，适合快速拉满/拉低
- `c = 1`：与原生线性一致

## 构建

用 Android Studio 打开本目录，Sync 后运行即可（首次会自动下载 Gradle 8.5）。

最低支持 Android 5.0（API 21）。

## 使用步骤

1. 打开 App，配置三段区间的上限（0-30 / 30-60 / 60-100）和各自倍率。
2. 点「保存并启用后台拦截」，会跳到系统无障碍设置。
3. 在无障碍设置里找到「精细音量」并开启。
4. 之后按物理音量键就会按你的映射精细步进。

测试按钮可以不开启无障碍就试效果（直接改系统音量）。

## 限制

- Android 12+ 与部分厂商 ROM 对无障碍服务拦截音量键有限制，若按键不生效，
  可改用 App 内「测试 +1 / -1」按钮，或扩展悬浮窗方案。
- 固定音量设备（如 Android TV、车载）无法改写系统音量，`isVolumeFixed()` 返回 true 时会提示。
